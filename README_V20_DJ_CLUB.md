# Red Moon Pub V20 — DJ Club

- DJ role is owner-created and server-enforced.
- DJ accounts are redirected from Staff Command to a DJ-only console.
- Public Red Moon pages show a realtime LIVE NOW indicator when a DJ is live.
- Dedicated Red Moon Club page with YouTube embed player, chat, listener presence and song requests.
- Requests are visually separated from normal chat and can be accepted/declined by DJ.
- Realtime updates use SSE with a polling fallback.
- YouTube links supported: watch, youtu.be, Shorts, embed and playlist links.
- YouTube content remains in the official embedded player; no audio extraction/downloading is implemented.
