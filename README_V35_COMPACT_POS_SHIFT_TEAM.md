# Red Moon Pub V35 — Compact POS + Shift Team Control

- Inventory product cards use shorter images and keep stock count over the image.
- Sales Log removes the old table minimum width and keeps invoice/delete actions inside the panel.
- Mobile remains card-based without horizontal scrolling.
- Open shifts can add registered non-DJ staff later.
- The shift starter can add members; MANAGER/OWNER can also add members.
- Added members are stored by user ID and name, and appear in the shift closing document.
- Shift member additions are audited and realtime state is broadcast.
