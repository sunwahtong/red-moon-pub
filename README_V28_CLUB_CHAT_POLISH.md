# Red Moon Pub V28 — Club Chat Polish

- GoCast remains the external live audio provider.
- No iframe and no mirrored GoCast page.
- Club chat shows at most 8 messages at once.
- Chat messages are kept for 60 seconds; the final 15 seconds fade out.
- Distinct visual treatments for normal chat, music requests, accepted requests, declined requests, and DJ messages.
- New Club chat activity has a short notification sound after the visitor interacts with the page.
- DJ can send a dedicated DJ message from the DJ console; it appears to everyone with a distinct style.
- DJ can moderate name requests, music requests and chat as before.
- Club listener heartbeat keeps the live listener count refreshed without F5.
- Club and DJ pages continue using realtime SSE plus polling fallback.
- GoCast listening button is centered inside the Club live/offline stage.
