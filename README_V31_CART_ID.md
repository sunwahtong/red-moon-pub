# Red Moon Pub V31 – CART ID

A V30 POS kosárrendszeréhez minden lezárt kosár kap egy egyedi, ember által olvasható Kosár ID-t.

Példa:
`KOS-20260918230015-A1B2C3`

A kosár összes eladási sora ugyanazt a Kosár ID-t kapja, ezért a Legutóbbi eladásoknál azonnal látható, mely tételek tartoztak ugyanahhoz a vásárláshoz.

A belső `transactionId` továbbra is megmarad a számlázás és az adatkapcsolatok számára.
