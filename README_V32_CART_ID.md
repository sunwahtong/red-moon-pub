# Red Moon Pub V32 — rövid Kosár ID

- A Kosár ID most az eladó nevének monogramja + sorszám az adott műszakon belül.
- Példa: Zhen Yu Xiao → ZYX01, majd ZYX02; Yuna Yue Rei → YYR01.
- A számlázási/eladási táblázat külön „Kosár ID” oszlopot kapott, így a Termék oszlop nem csúszik el.
- Az új ID-számláló műszakonként és dolgozónként külön fut, törölt eladás után sem használ újra sorszámot.
- A régi hosszú KOS-... azonosítók induláskor át lesznek alakítva az új rövid formára.
