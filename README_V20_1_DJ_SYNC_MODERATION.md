# Red Moon V20.1 — DJ sync + chat moderation

- DJ playback state is synchronized to public Club clients (track, play/pause, seek position, playlist item).
- Public chat requires a display-name request approved by a DJ.
- 5-second server-side cooldown for chat and music requests.
- DJ can approve/decline names.
- DJ can ban a chat IP for a selected duration with a mandatory reason.
- Chat and music-request events have distinct lightweight notification sounds.
- Public player remains an official YouTube embedded player. YouTube content is not downloaded or split into audio-only playback.
